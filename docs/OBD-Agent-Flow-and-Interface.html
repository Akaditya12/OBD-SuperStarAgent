OBD SuperStar Agent

blackNgreen · Product overview & agent system

What this product is

OBD SuperStar Agent is an AI application for telecom and VAS teams who need outbound dialer (OBD) campaigns: short, persuasive call scripts and ready-to-play audio in the right language and regional style.

You provide a product description (or paste a script) and choose country, operator, and language. The system runs a chain of specialised AI agents that analyse the product, research the market, write and critique scripts, choose a voice, and produce mixed audio (voice + optional background music).

What you get at the end:

  • Multiple script variants (hook, body, CTA, fallbacks) tuned to the market.
  • Audio files you can download and use on your OBD platform.
  • Optional save to a dashboard for later access and handover.

The six agents (main pipeline)

Each agent is a dedicated step. Together they form one pipeline from raw product input to final audio. The next agent always uses the output of the previous steps.

Agent Role Input → Output
1. Product Analyzer Turns unstructured product material into a clear brief. In: Product document (PDF/text). Out: Structured brief—features, benefits, pricing hooks, subscription/IVR angles—so later agents do not guess.
2. Market Researcher Builds a market picture for the chosen country and telco. In: Brief + country + telco. Out: Audience traits, cultural notes, tone guidance, and promotion ideas so scripts sound local and relevant.
3. Script Writer Writes the actual OBD scripts in the required language and length. In: Brief + market analysis + language choice. Out: Several variants, each with hook (~5s), body (~18s), CTA with clear DTMF, fallbacks, and polite close—formatted for TTS (tags stripped before speech).
4. Eval Panel Quality-checks scripts before audio is produced. In: Script variants. Out: Scores and written feedback from multiple “personas” (e.g. clarity, cultural fit, CTA strength). Feeds back into revision if you use that loop.
3 again — Revision Rewrites scripts using eval feedback. In: Original scripts + eval feedback. Out: Revised variants that keep the same structure but address weaknesses flagged by the panel.
5. Voice Selector Chooses which voice fits the market and script tone. In: Scripts + market context + available voices. Out: Primary voice plus alternatives, with rationale—so audio matches region and campaign style.
6. Audio Producer Generates speech and mixes it for broadcast use. In: Final script text + chosen voice + country (for accent/voice pool) + BGM choice. Out: MP3 (or WAV) files—hook previews first, then full mixed audio via TTS (ElevenLabs preferred, then Murf, then free edge-tts) plus optional background music.
Script to Voice (separate mode): If you already have a script, you do not need agents 1–5. You paste the text and only Agent 6 (Audio Producer) runs—same TTS stack, country-based voices, speed control, and optional “lock voice” so the next script uses the same voice without picking again.

How the interface maps to the pipeline

The home page is the campaign wizard: upload product file, set country/telco/language, then start. Progress is shown step by step; when analysis for the same market was saved before, the app can offer to reuse it and skip earlier agents.

When the pipeline finishes, the results screen shows script variants, lets you edit or translate, play short previews per voice, pick a voice, and generate full audio—then save the campaign to the dashboard for your team.

Script to Voice is a separate page: paste script → preview voices → generate final file → download or save—ideal when the script is already written and you only need consistent audio.
