The Engine
6-Agent AI Pipeline
An orchestrated sequence of specialized AI agents transforms a product document into broadcast-ready campaign assets.
01

Product Analyzer

Extracts a structured brief from raw product documentation — features, pricing, CTA shortcodes, audience, USPs. Treats input as data only (injection prevention).

AGENT 1 · ~4K TOKENS
02

Market Researcher

Deep-dives into the target country, telco, and culture: communication style, taboos, emotional triggers, competitive landscape, best call times. Runs in parallel with Step 1.

AGENT 2 · PARALLELIZABLE
03

Script Writer

Generates 5 creative variants (curiosity gap, humor, storytelling, FOMO, aspirational). Each with hook, body, CTA, 2 fallbacks, polite closure, and emotion tags like [warm], [pause].

AGENT 3 · 5 VARIANTS × 75 WORDS
04

Evaluation Panel

10 expert personas score each variant 1–10, then consensus-rank them to surface the strongest scripts.

AGENT 4 · CONSENSUS RANKING
05

Script Writer (Revision)

Rewrites all variants incorporating the evaluation panel's critical feedback and revision instructions. Configurable rounds (default: 1).

FEEDBACK LOOP · CONFIGURABLE ROUNDS
06

Voice Selector + Audio Producer

Selects region-appropriate voices from 18+ curated ElevenLabs voices. Generates hook previews (3 voices per variant). User picks favorites, then triggers full audio with BGM mixing.

AGENT 6+7 · TWO-PHASE AUDIO

Capabilities
Key Features
🚀

Full Campaign Pipeline

Upload product doc, set market, get 5 script variants + expert evaluation + audio — all in one flow.

🎤

Script to Voice

Paste any script, pick a country, preview 3 voices, generate final audio with BGM. Voice locking for repeat runs.

🔨

Flow Configs (IVR)

Multi-step IVR scripts: welcome → pack details → double consent → thanks. One audio file per step.

📊

Dashboard

Saved campaigns, play/download audio, edit scripts inline, translate to English, regenerate per-variant or all.

🤝

Real-Time Collaboration

Comments per campaign, presence indicators, activity feed. WebSocket-powered live updates.

⚙️

Admin Panel

Tune pipeline params (word limits, variant count, eval rounds), override agent prompts, manage users & roles.

🔒

Smart Caching

SHA256-keyed analysis cache. Exact match skips 2 agents, partial match skips 1. Saves time & API cost.

🎨

6 UI Themes

Light, midnight, ocean, ember, forest, lavender. Glassmorphism design with CSS variable theming.

🔐

Dual Auth

Supabase JWT with bcrypt + roles (admin/member), or env-based fallback for local dev. 72-hour tokens.
